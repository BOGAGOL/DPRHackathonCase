RUNBOOK MIGRASI PLAINTEXT KE PROTECTED V2

PRE-CHECK
[ ] Pemilik perubahan dan data ditentukan.
[ ] Backup-restore terbukti.
[ ] Disk, WAL, lock, dan replikasi dalam ambang.
[ ] Kunci dan policy OpenBao tersedia.
[ ] Migrator dan rollback diuji di staging.
[ ] Feature flag tersedia.

LANGKAH
1. Terapkan skema expand tanpa menghapus v1.
2. Aktifkan dual-write secara terbatas.
3. Set paused=false pada migration_control.jobs.
4. Jalankan migrator dengan batch kecil.
5. Pantau error, p95/p99, WAL, disk, lock, dan replica lag.
6. Hentikan bila melewati stop condition.
7. Lanjutkan; rekonsiliasi akhir tanpa SKIP LOCKED.
8. Validasi jumlah, tag AES-GCM, blind index, dan versi kunci.
9. Alihkan read ke v2, hentikan write plaintext, observasi.
10. Pensiunkan plaintext setelah persetujuan dan pemetaan semua salinan.

STOP CONDITION
- Gagal autentikasi ciphertext.
- Duplikasi atau kehilangan record.
- Error, latensi, replica lag, disk, atau WAL melewati ambang.
- OpenBao tidak stabil.

BUKTI
- Count sumber/target, record gagal, versi kunci, plaintext scan,
  benchmark, restore drill, dan persetujuan cutover.
